# NovaStore E-Ticaret Veri Yönetim Sistemi

Bu proje,TNC GROUP çatısı altında, Software Persona'nın 11. Yazılım Stajı kapsamında Veri Tabanı ve SQL  Eğitimi Proje'si için; SQL Server kullanılarak geliştirilen ilişkisel veri tabanı tasarımı ve analiz çalışmasını içermektedir.

## İçerik
- DDL (Tablo Oluşturma)
- DML (Veri Ekleme)
- DQL (Sorgular)
- View
- Backup Script
